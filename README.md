# Magazin_odejdi
Добро пожаловать в репозиторий проекта магазин одежды "Clothing_store"
Этот сайт создан для того, чтобы люди могли делать покупки по душе. Здесь можно посмотреь какая одежда присутствует в ассортименте, узнать их цену, а также связаться с нами для заказа.

# Функционал
1. Представление ассортимента одежды
2. Информация об одежде
3. Контакты для оформления заказа или обратной связи
